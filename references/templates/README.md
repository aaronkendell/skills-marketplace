## Workflow

```
/planner research {app} {idea}
    → generates: prd.md, architecture.md, system-design.md, app-readme.md

/planner initiative {app}
    → generates: initiative.md, design.md

/planner project {initiative-path}
    → generates: project.md, technical-design.md

/planner feature {issue-path}
    → generates: issue.md, {id}-plan.md

/planner implement {LINEAR-ID}
    → reads issue.md + plan.md → implements → PR
```

## Issue types

`issue.md` covers three types via the `type` frontmatter field:

| Type | Use for | Key sections |
|------|---------|-------------|
| `feature` | New functionality | What to build, acceptance criteria |
| `bug` | Something broken | Reproduction steps, expected vs actual |
| `research` | Spikes, decisions | Key questions, deliverable |
